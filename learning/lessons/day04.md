## 1. 从写死数据变为输入数据

之前每次测试都要修改源码里的数字。Scanner 可以在程序运行后，从控制台接收输入。

```java
import java.util.Scanner;

public class ReadAge {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("请输入年龄：");
        int age = scanner.nextInt();
        System.out.println("你输入的年龄是：" + age);
    }
}
```

`import` 引入 Scanner 类；`new Scanner(System.in)` 创建读取标准输入的对象；`nextInt()` 等待并读取一个整数。程序停在输入处通常是在等你输入，不是卡死。

在 IDEA 点击运行后，点击下方 Run 控制台，输入内容，再按 Enter。需要测试第二组数据时，重新运行程序即可；本课还不需要循环。

## 2. 三种读取方法

| 方法 | 返回类型 | 作用 |
|---|---|---|
| nextInt() | int | 读取一个整数，如 120 |
| nextDouble() | double | 读取一个浮点数，如 12.5 |
| nextLine() | String | 读取当前行剩余文本，消费行结束符 |

每次调用都会消费输入中的一部分。连续读两个整数时，输入可以用空格或换行分隔；按提示逐行输入最容易理解。

## 3. 混用数字与整行文本

```java
int age = scanner.nextInt();
scanner.nextLine();
String city = scanner.nextLine();
```

假设你输入年龄后按 Enter，nextInt 只读走数字，行结束符还留着。紧接着调用 nextLine，通常会读到数字后剩下的空内容。所以例子中先用一次 nextLine 消费数字所在行的剩余内容，再读下一行城市。

不要每次 nextInt 后都机械添加 nextLine：如果后面仍然是 nextInt，就不需要专门消费换行。今天主练习先读姓名，再读数字，可以避开这个问题；示例会演示混用方式。

## 4. 运行示例

运行 `src/main/java/learning/day04/InputDemo.java`，依次输入：

```text
3
12.5
蓝色本子
```

预期得到数量 3、单价 12.5、备注“蓝色本子”，总价 37.5。这里用小数价格练习 nextDouble，不代表以后正式记账可以用 double 精确存储金额。

示例用 `Locale.ROOT` 让小数输入统一使用英文点号。`try (Scanner ...)` 会在结束时关闭 Scanner；本课可以照着使用，资源管理稍后系统讲解。它也会关闭 System.in，所以每个程序只创建并共用一个 Scanner。
