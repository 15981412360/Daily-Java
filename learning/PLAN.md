# Java 后端学习任务表

## 时间预期与目标

这是学习规划估计，不是完成时间保证。按每周 14 小时：

- 第 4～6 周：能使用常用基础语句，编写简单控制台程序。
- 第 10～12 周：能把对象、集合、异常和文件操作组合起来解决小问题。
- 第 20～24 周：能在指导下完成 Maven + Spring Boot + 数据库的增删改查服务。
- 第 24～36 周：逐步达到独立完成小型后端、编写测试、定位常见错误的目标。

整体预留 **6～9 个月，约 336～504 小时**。本表采用 **32 周、448 小时**的中间方案。遇到考试、工作或知识难点时顺延；连续两周练习太简单时再加快。这里的“熟练”指上述可验收能力；大型系统架构、深入 JVM、复杂并发等需要后续实践。

## 每天两小时

| 用时 | 任务 | 当天产出 |
|---|---|---|
| 10 分钟 | 不看笔记回忆昨天的知识 | 口头解释或小题 |
| 25 分钟 | 阅读当天讲义、运行并修改例子 | 理解一个新知识点 |
| 55 分钟 | 独立写练习或实现一个小功能 | 自己编写的代码 |
| 20 分钟 | 阅读批改、修改并重新运行 | 修正后的结果 |
| 10 分钟 | 写日志、整理 Git 提交 | 学习记录 |

每周第 1～5 天推进新内容，第 6 天综合练习，第 7 天用于复习、补漏和下周规划。第 7 天也计入两小时，不用额外加班；有缺课先补课，不同时堆叠新任务。

## 批改与升阶规则

1. 你保存文件并告诉助手当天任务已完成。
2. 助手读取实际文件，必要时编译运行，检查题目要求、结果、边界、可读性与知识理解。
3. 报告区分“必须修正”和“可选改进”，给出文件位置、错误原因及提示。
4. 先由你修正；同一个难点反复卡住时补一个更小的例子。
5. 正常与边界用例通过、你能解释自己的代码、能做一道变式题后过关。
6. 通过后更新进度与日志，记录到 GitHub，再准备下一课。

最终验收：从需求拆出任务；用 Maven 构建；设计并操作数据库；编写分层 Spring Boot API；正确校验参数和处理异常；写关键测试；按说明启动服务；使用 Git 提交并解释修改；不看完整答案完成一次小功能迭代。
