# Day05 概念辨析（学习者作答）

每题几句话即可。这里不要求总结编程题的运行结果或填写测试表。

## 1. 类型与数据

数据类型有什么作用？`boolean enabled = true;` 与 `String enabledText = "true";` 分别保存什么，为什么不宜把它们当成同一种数据？

我的回答：数据类型的作用是方便计算机进行运算，boolean代表的是正确与错误，String代表的是一个字符串。

## 2. 短路与执行顺序

什么是逻辑运算的短路？在右侧表达式可能出错或执行额外操作时，为什么是否执行右侧会影响程序？请用一个独立于成绩/入场题的场景说明，不需要写完整程序。

我的回答：即在左侧运算就可以代表整个式子的结果时，就不进行剩余的运算。当右侧表达式出错或需执行额外操作时，若左侧即可决定整个式子的正误，则不必执行右边，可跳过代码的错误部分或提升效率。
如if(2==2或(计算此时的地月距离==0.03AU))，这样既可显著看到，当左侧正确时，跳过右侧可使得运算速度大大加快。

## 助手审阅

审阅日期：2026-11-03。原回答保留，以下为助手补充。

1. 类型题方向基本正确，需要更精确：数据类型规定可表示的值及可执行的操作，并帮助编译器检查使用方式。boolean 表示条件的真/假，不能简单等同于程序正确/错误；例如 isForbidden 为 true 只表示“禁止条件成立”。String "true" 是由字符组成的文本，不能直接作为 if 的条件，也不能直接参与 && 运算。无需为此重新抄写本题。
2. 短路题基本通过。你已经说明“左侧决定整体结果时跳过右侧”，并给出避免额外计算的独立场景。准确规则是：&& 左侧为 false 时短路，|| 左侧为 true 时短路。你的“或”是概念示意，实际 Java 应写 ||。
3. “跳过错误部分”需要限定：短路可以避免执行右侧而产生的运行时错误，例如整数除以零，但不会免除 Java 编译器对右侧语法和类型的检查。另外，如果右侧必须执行某项操作，就不能依赖它一定在短路表达式中运行。
