## 1. 从你的 Day01 代码开始

你的计算是：

```java
int totalHours = totalMinutes / 60;
```

840 / 60 能整除，结果为 14。假如总分钟数是 125，整数除法会得到 2，剩余部分被截去（向零截断）。这不代表 `/` 永远只能算整数，而是两个操作数都是整数时执行整数除法。

```java
int minutes = 125;
double first = minutes / 60;
double second = minutes / 60.0;
double third = (double) minutes / 60;
```

先计算右边，再赋值给左边：

- first：先得到整数 2，再转换为 double 的 2.0。小数部分不会因为左边是 double 而恢复。
- second：60.0 是 double，这次进行浮点除法，结果约为 2.083333。
- third：先把 minutes 的值转换成 double，再做除法。原来的 minutes 变量仍然是 int，值仍为 125。

## 2. 今天需要的类型

| 写法 | 含义 | 示例 |
|---|---|---|
| int | 32 位有符号整数，适合本课的小整数 | int count = 6; |
| double | 双精度浮点数，可表示小数，但不保证十进制精确 | double length = 3.5; |
| String | 文本；加双引号的数字仍是文本 | String label = "6"; |

`int count = 6.5;` 无法直接编译，因为 Java 不会自动把 double 缩窄为 int。`int count = (int) 6.5;` 可以编译，得到 6；强制转换不是四舍五入。

double 适合今天的温度和平均值练习。以后处理钱时会学习 BigDecimal，不依赖 double 精确表示金额。

## 3. 赋值与重新计算

```java
int quantity = 4;
int doubled = quantity * 2;
quantity = 7;
```

此时 doubled 仍是 8。它保存的是执行赋值时算出的结果，不是会自动更新的公式；想重新计算，需要再次执行 `doubled = quantity * 2;`。

你在 Day01 中每次调用 out 方法都会重新计算局部变量，所以修改天数后的结果能变化。
