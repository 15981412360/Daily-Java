## 1. 条件成立才执行

```java
int battery = 15;
if (battery < 20) {
    System.out.println("电量低，请充电");
}
```

if 括号内必须是 boolean 表达式；为 true 执行大括号内语句，为 false 跳过。执行完选中的分支后继续往下运行，除非遇到 return 等控制语句。

固定保留大括号，即使分支内只有一句，也能减少以后加代码时的误解。不要在 `if (...)` 后面直接加分号，分号会成为一个空语句，后面的代码块就不再受这个 if 控制。

## 2. if / else 二选一

```java
if (battery < 20) {
    System.out.println("需要充电");
} else {
    System.out.println("电量充足");
}
```

本次执行只会选择其中一支。else 不需要再写“相反条件”，它对应前面 if 为 false 的情况。

## 3. 多个 if 与 else if 链

多个独立 if 会分别检查，可能执行多段代码；if / else if / else 从上到下选择第一个满足的分支，后面的分支不再检查。

```java
if (battery < 20) {
    System.out.println("低电量");
} else if (battery < 80) {
    System.out.println("电量正常");
} else {
    System.out.println("电量较高");
}
```

条件会重叠时，顺序尤其重要。如果先判断 battery < 80，15 就会被提前归为“正常”，无法再进入后面的低电量分支。

## 4. 先识别无效输入，再判断业务

Day05 的问题来自“条件含义”和“分支动作”没有对应：如果条件表示无效，就应当在该分支拒绝或报错；如果分支表示允许，就需要条件表示有效。

运行 `src/main/java/learning/day06/BranchDemo.java`。它先排除 0～100 以外的电量，再按范围分类。分别输入 -1、0、19、20、79、80、100、101，自行观察即可，不用抄结果。

注意：这里处理的是“输入是整数，但数值不合要求”。用户输入字母导致 nextInt 读取失败的问题，要等异常或输入校验章节再处理。

## 5. 编程题 A：比较两个整数

在 `CompareNumbersPractice.java` 中依次读取两个 int，输出且只输出一条结果：

- 两数相等：输出“两数相等”。
- 否则：输出“较大值：”和较大的那个数。

要求使用 if/else 分支完成，不使用 Math.max 或三元表达式。允许负数和 int 全范围；不要通过两数相减的正负判断大小，因为差值可能超出 int 范围。直接比较两个数即可。

| 输入 | 预期结果 |
|---|---|
| 8 3 | 较大值：8 |
| 3 8 | 较大值：8 |
| 5 5 | 两数相等 |
| -3 -8 | 较大值：-3 |
| 0 -1 | 较大值：0 |
| -2147483648 2147483647 | 较大值：2147483647 |

可以用嵌套 if/else，也可以用 else if；每次运行处理一组输入。

## 6. 编程题 B：判断闰年

在 `LeapYearPractice.java` 中读取一个 int 年份。本题采用公历闰年规则，接受 1～9999 的年份；对该范围内所有年份统一应用规则，不讨论历史历法切换。

规则：

- 能被 400 整除的年份是闰年。
- 其他年份中，能被 4 整除但不能被 100 整除的年份是闰年。
- 其余是平年。
- 不在输入范围内时，只输出“年份无效”，不要再输出闰年或平年。

合法输入时输出“闰年”或“平年”。先考虑如何划分有效/无效，再处理闰年条件；使用 % 判断整除。可先用 boolean 表达条件，再用分支决定输出。

| 输入 | 预期结果 |
|---|---|
| 2024 | 闰年 |
| 2023 | 平年 |
| 1900 | 平年 |
| 2000 | 闰年 |
| 2100 | 平年 |
| 2400 | 闰年 |
| 1 | 平年 |
| 9999 | 平年 |
| 0 | 年份无效 |
| -4 | 年份无效 |
| 10000 | 年份无效 |

保证输入格式为 int，不要求处理文本输入错误，不使用日期库代替条件判断，也不需要循环。
