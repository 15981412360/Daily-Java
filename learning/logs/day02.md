## 预测与解释

1. `double value = 7 / 2;` 的结果与原因：可将整数值赋给一个双精度浮点数。
2. `(double) (7 / 2)` 和 `(double) 7 / 2` 的区别：一个是3.0，即将7/2整个化为小数，另一个是3.5，即先将7化为小数，再计算
3. 改变 quantity 后，doubled 为什么不会自动更新：因为doubled已经写入磁盘，所以无法更新。
4. Git 与 GitHub 的区别：Github是一个可被Git使用的网站。
5. add、commit、push 分别做什么：add是要添加什么至本地暂存区，commit是将目标文件放置在本地的仓库，push是上传至云端的仓库。
6. 已经 add 后又编辑文件，提交前要做什么：重新diff。

两个容易误判的表达式实际上写对了：

- `c * 9 / 5`：乘除同优先级，从左向右分组，先算 double 类型的 c * 9，再除以 5，所以保留小数。与 `c * (9 / 5)` 不同；后者先把括号中的整数除法算成 1。
- `total / 3`：total 已声明为 double，所以是浮点除法，不会丢掉平均分的小数。若未来把 total 改为 int，就要重新考虑除法的操作数类型。
